# POMatch

Private, browser-based three-way matching of purchase orders, goods received, and supplier invoices. This is an early-access pilot by Nytto Labs. CSVs are processed locally and not uploaded. Currency setting changes display only; no conversion.

Try the sample data in the web app, or provide three CSVs with matching SKUs, quantities and unit prices. Check source documents before paying or disputing invoices.
